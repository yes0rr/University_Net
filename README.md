# University_Net

Интерактивная карта вузов России с подбором по баллам ЕГЭ.
Кликаешь город на карте → в панели появляются вузы, проходные баллы и направления.

**Данные:** 6 вузов Томска (34 комбинации предметов, 81 направление) + база по Москве,
Санкт-Петербургу, Новосибирску, Казани и Екатеринбургу.

---

## Быстрый старт

### Вариант 1. Просто открыть файл (сервер не нужен)

Открой `frontend/index.html` двойным кликом. Всё работает локально, без Python
и без интернета — данные лежат в `frontend/data.js`.

### Вариант 2. Запустить сервер

**Windows** — двойной клик по `start.bat`. Скрипт сам создаст окружение,
поставит зависимости, поднимет сервер и откроет браузер.

**Вручную (любая ОС):**

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

Открыть: **http://127.0.0.1:8000**

| Адрес | Что там |
|---|---|
| `/` | Карта вузов |
| `/docs` | Автодокументация API (Swagger) |
| `/api/universities/RU-MOW` | API: вузы Москвы |
| `/data/tomsk.json` | JSON с баллами вузов Томска (его читает панель) |
| `/data/subj.json` | JSON со справочником направлений |

## Структура проекта

```
frontend/
  index.html        страница: SVG-карта России (86 регионов, 87 городов)
  script.js         логика карты, зум, калькулятор ЕГЭ, регистрация
  styles.css        тёмная тема
  data.js           данные + логика панели: генерируется, вручную не править
  tomsk-loader.js   подгрузка данных из data/*.json через fetch
  russia-map.js     SVG-карта строкой (чтобы работало через file://)
  russia-map.svg    та же карта файлом (для редактирования)

data/
  tomsk.json        баллы вузов по 34 комбинациям предметов
  subj.json         справочник направлений: ID → «код + название»

tools/
  build_tomsk_data.py   генератор frontend/data.js из Vuzanet(1).xlsx
  tomsk_frontend.js     логика панели Томска (здесь правятся тексты и вид)
  test_frontend.js      автотест фронтенда (37 проверок)

Vuzanet(1).xlsx     исходная таблица: баллы вузов и направления
main.py             FastAPI: раздача фронтенда + API вузов по регионам
```

**Источник правды — JSON в `data/`.** При загрузке страницы `frontend/tomsk-loader.js`
забирает его через `fetch`, приводит к нужному виду (строки `"230"` → числа,
`"—"` → `null`, `ID-001` → «09.03.04 Программная инженерия») и обновляет панель.
Правки в JSON видны после перезагрузки страницы — пересборка не нужна.

`frontend/data.js` — та же информация плюс логика панели. Нужен для случая,
когда `index.html` открыт двойным кликом: браузеры запрещают `fetch` на `file://`,
и панель работает на этих данных. Если JSON не загрузился, в консоли появится
предупреждение, но страница продолжит работать.

## Как это работает

1. **Клик по Томску или по Томской области** на карте. Точка города вызывает
   `selectCity()` в `script.js`; для области связку «регион → город» добавляет
   логика панели (словарь `REGION_TO_CITY`).
2. Для Томска `updateSidebarUnis()` подменяется логикой из `data.js`
   (`tools/tomsk_frontend.js`), для остальных городов работает оригинал.
   Панель наполняется сразу — список вузов не зависит от выбора предметов.
3. **Два режима панели:**
   - *Обзор* (направление не выбрано) — все 6 вузов, диапазон проходных баллов
     по всем комбинациям, число направлений.
   - *Направление выбрано* — вузы сортируются по проходному баллу, а те, у кого
     этого направления нет, отбрасываются. Для оставшихся виден проходной балл
     и метка «Проходит / Не хватает» по сумме баллов ЕГЭ.

**Ключевой выбор — направление, а не комбинация предметов.** Направление
однозначно определяет нужные предметы ЕГЭ, поэтому комбинация подставляется
автоматически, а подходящие направления поднимаются в начало списка
(группа «Подходят под ваши предметы»).

Соответствие предметов: `Математика (профиль)` → `мат`, `Информатика` → `инфа`,
`Иностранный язык` → `ин-яз` и т. д. Русский язык обязательный и в комбинациях
не участвует.

## Обновление данных

**Баллы и направления** — правь `data/tomsk.json` и `data/subj.json`. При запущенном
сервере достаточно перезагрузить страницу: данные подтянутся свежими.

**Офлайн-копию** (для открытия двойным кликом) пересобираешь скриптом:

```bash
pip install openpyxl
python tools/build_tomsk_data.py     # перезапишет frontend/data.js из Vuzanet(1).xlsx
```

Если таблица и JSON разошлись, актуальны JSON: именно их читает страница,
запущенная через сервер. **Не правь `frontend/data.js` вручную** — перезапишется.

Текст подсказок, вид карточек и логика живут в `tools/tomsk_frontend.js`:
правишь его → запускаешь генератор.

**Добавить вуз:** назови столбец в xlsx одним из ключей из списка `UNIVERSITIES`
в `build_tomsk_data.py` и допиши тот же ключ в `UNIVERSITIES` в `tomsk-loader.js`.
**Добавить город:** допиши `UNIVERSITIES_DB` в `main.py` и `CITY_BY_REGION`
в генераторе. Чтобы клик по области открывал город, добавь связку в словарь
`REGION_TO_CITY` в `tools/tomsk_frontend.js` (сейчас там «Томская область» → Томск).

```bash
npm install jsdom

```

50 проверок: клик по точке Томска **и по Томской области**, мгновенное
наполнение панели, фильтрация и сортировка вузов по направлению, отбрасывание
вузов без направления, расчёт баллов, метки «Проходит / Не хватает»,
прозрачный ноль и лимит 100 в полях ЕГЭ, переключатель бюджет/платное,
работа остальных городов, а также разбор JSON загрузчиком: строки `"230"` →
числа, `"—"` → `null`, `ID-001` → название направления.

## Известные ограничения

- В таблице одна цифра на вуз — без разделения бюджет/платное. При переключателе
  «Платное» показывается тот же балл с пометкой.
- **Баллы хранятся по (комбинация предметов × вуз), а не по (направление × вуз).**
  Поэтому все направления внутри одной комбинации дают одинаковый проходной балл:
  «Программная инженерия» и «Лесное дело» (обе — мат/инфа) показывают одни числа.
  Чтобы развести их, нужен столбец баллов на каждое направление.
- Баллы берутся из `data/*.json`, а не из API `/api/universities/`. Для Томска
  JSON подробнее: в нём разбивка по комбинациям предметов и направления, которой
  в схеме API нет. Другие города по-прежнему рисуются из `uniData`.
- Если открыть страницу двойным кликом (без сервера), `fetch` не работает и
  панель показывает данные из `data.js` — офлайн-копии JSON.
- Вузы заполнены для 6 городов (Томск + 5 из `main.py`). Для остальных городов
  на карте данных пока нет.
- `russia-map.svg` не используется в рантайме (подключается `russia-map.js`) —
  оставлен как редактируемый исходник карты.
